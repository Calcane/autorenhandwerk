Datenschutzerklärung

Diese Erklärung beschreibt die Datenbearbeitung beim aktuellen technischen Stand von Autorenhandwerk.com: eine statische Website ohne eigenes Analyse-, Werbe- oder Nutzerkontosystem.

Kurzfassung

Die Website selbst verwendet derzeit keine Formulare, Newsletter-Anmeldung oder eigenen Analyse- und Marketingtracker. Das Hosting erfolgt über GitHub Pages; dabei verarbeitet GitHub technisch notwendige Zugriffsdaten.

Hosting über GitHub Pages

Autorenhandwerk.com wird derzeit über GitHub Pages, einen Dienst von GitHub, bereitgestellt. Beim Aufruf einer GitHub-Pages-Website wird nach Angaben von GitHub die IP-Adresse des Besuchers zu Sicherheitszwecken protokolliert und gespeichert. Daneben können technisch erforderliche Verbindungs- und Protokolldaten durch die Hosting-Infrastruktur verarbeitet werden.

Die konkrete Speicherdauer und weitere Verarbeitung dieser Daten durch GitHub richten sich nach den jeweils geltenden Angaben und Datenschutzbestimmungen von GitHub.

Keine eigene Datenerhebung über Formulare oder Konten

Im aktuellen Quellcode von Autorenhandwerk.com gibt es keine Kontaktformulare, Nutzerkonten, Kommentarfunktionen, Newsletter-Anmeldung oder Bestellstrecke. Über solche Funktionen werden daher derzeit keine Personendaten direkt durch Autorenhandwerk erhoben.

Cookies, Analyse und Tracking

Autorenhandwerk.com bindet derzeit keine eigenen Webanalyse- oder Marketingtracker und keine Werbenetzwerke ein. Der Seitencode setzt nach aktuellem Stand bewusst keine Analyse- oder Marketingcookies.

Davon zu unterscheiden sind technisch bedingte Datenbearbeitungen durch den Hostinganbieter oder durch externe Seiten, die du über einen Link aufrufst.

Bearbeitung und Übermittlung ins Ausland

GitHub ist ein international tätiger Anbieter. Nach der aktuellen Datenschutzerklärung von GitHub können Personendaten unter anderem in der jeweiligen Region, in den Vereinigten Staaten und in weiteren Ländern verarbeitet werden. GitHub nennt für internationale Übermittlungen unter anderem Standardvertragsklauseln und die Teilnahme am Swiss-U.S. Data Privacy Framework als Schutzmechanismen.

Externe Links

Beim bloßen Besuch dieser Website werden externe Zielseiten nicht automatisch geöffnet. Wenn du einen externen Link anklickst, gelten für die dortige Datenbearbeitung die Bedingungen und Datenschutzhinweise des jeweiligen Anbieters.

Rechte betroffener Personen

Nach dem schweizerischen Datenschutzrecht können betroffene Personen insbesondere Auskunft über die Bearbeitung ihrer Personendaten verlangen und – soweit die gesetzlichen Voraussetzungen vorliegen – Berichtigung oder Löschung verlangen. Anfragen hierzu können an datenschutz@autorenhandwerk.com gerichtet werden.

Änderungen dieser Erklärung

Wenn später beispielsweise Analysewerkzeuge, Newsletter, Formulare, eingebettete Medien, Shops oder andere technische Dienste hinzukommen, wird diese Datenschutzerklärung entsprechend dem tatsächlich eingesetzten System aktualisiert.
